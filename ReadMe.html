Abstract Syntax Tree (AST) interpreters in Python, Java, and C-Language

The Springleik Project is an effort to study and quantify the use of small domain-specific languages (DSLs) in coding embedded applications for measurement and control. The Toy Motor demo presented here simulates the operation of three actuator motors configured to divert products on a conveyor from an input stream to one of four output streams. Also presented are AST example programs in several host languages:

  • Python Skeleton interpreter along with worked-out examples implementing motion control simulations using Springleik AST techniques.
  • Java Skeleton interpreter runs on the command line, produces JSON output with some console text.
  • C-Lang Skeleton interpreter runs on the command line, produces JSON output with some console text.

Each of these folders has its own ReadMe file explaining what’s there and how to use it. Comments and concerns are always welcome. A preprint giving many details of this work has been posted on EngrXiv:
